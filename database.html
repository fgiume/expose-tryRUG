Search the Evidence

Search coded examples and the complete text of the project's episode documents. Results are ranked by BM25 keyword relevance, with filters for cases, sanctions, strategies and tactics.

Search methodology. Both coded excerpts and episode documents use BM25 relevance ranking (k1 = 1.2, b = 0.75) when keywords are entered. Ranking reflects word frequency, rarity across the collection and document length, not evidentiary reliability. Stopwords are excluded and matching ignores case and accents. With an empty search, results appear in source order. About the evidence. This tool uses EXPOSE research documents and coding, not internet search results. A document match means that a keyword occurs in that episode document; a coding filter selects documents containing at least one corresponding coded record. These need not be the same passage. The source documents are not the complete UN Panel of Experts reports.

Explore the Data

Choose what appears on the rows and columns. Each matrix cell tells you whether the two variables occur together in the same documented coded example, not merely in the same country or episode.

YES · 1

At least one documented example has both selected variables coded together. Select YES to see up to 15 supporting examples.

NO · 0

No co-coded example is found in the selected scope where the coding is informative. This does not prove that evasion never occurred.

NO DATA · 9

Insufficient information to assess the combination, including episodes with no relevant sanctions imposed or no information available.

Scope: A case includes all its episodes; selecting one episode restricts the comparison strictly to that episode. Uninformative rows and columns are hidden by default, but the missing-data values are preserved and can be displayed using the checkbox. Method: YES is evaluated at the individual source-excerpt level (Option B). NO and NO DATA use the project's episode-level 0 / 1 / 9 coding from Database 3.0. Missing information is never counted as NO. Repeated coding rows referring to the same excerpt are grouped as one example. Data collection ends 31 December 2025.

Supporting evidence

Interpretive limits. The matrix reports patterns in the evidence collected and coded by EXPOSE, not the prevalence of sanctions evasion in the world. The absence of a recorded combination is not evidence that it never happened. The Excel workbook uses 1 for found/used, 0 for not found/not used, and 9 for unavailable information; the table preserves these distinctions.
